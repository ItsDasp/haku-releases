![Haku Text Editor](https://i.imgur.com/2m2MPF9.png)

> **"Not an IDE. But your IDE."**

A lightweight code editor built with [Tauri](https://tauri.app/), focused on simplicity, speed, and customization.

Haku is made as an escape from increasingly bloated and AI-heavy development tools. No accounts, no cloud requirements, no built-in AI trying to do everything for you.

Just an editor, a shell, and a powerful plugin system.

## Make it yours

Haku isn't trying to decide what your development environment should look like.

It gives you the tools to build it yourself.

Haku comes with a plugin API that lets you extend the editor and add the features you actually want. Want Git integration? Build a plugin. Want AI? Build a plugin. Want something completely ridiculous? You can probably build a plugin for that too.

And if the API doesn't give you enough power to build what you want, that's not a reason for Haku to add the feature itself.

It's a reason to make the API more powerful.

> **"Don't buy the fish. Go fish yourself."**

Plugins can be created and built using Haku's own tooling:

```bash
haku create
haku build
```

The goal is for Haku's core to stay small while the things you can build with it keep getting bigger.

## Lightweight by design

![Appearance Tab](https://i.imgur.com/FF1RLwI.png)

Open folders and workspaces in a minimal interface designed to stay fast without unnecessary clutter.

Haku also includes an integrated shell, so you can keep your existing workflow without needing every development tool built directly into the editor.

You can also open image and video files directly inside Haku for quick previews.

Maybe someday it'll support PDFs, spreadsheets, presentations, and other file types too. orr... you can make it yourself


## Still in beta

![Haku Itself](https://i.imgur.com/rsWS3f6.png)

Haku is not a full IDE. at least not by default.

And that's kinda the point.

The goal is to make a modern editor that feels comfortable to use without turning it into a massive development suite that tries to do everything for you.

The entire project is currently being developed by one person, so some things may still be a little rough around the edges.

Haku is also planned to become fully open source in the future.

Since the project is still in beta, bugs and weird behavior may happen sometimes.

Feedback, bug reports, and suggestions are genuinely appreciated lol.

If something is missing from Haku, don't assume it belongs in the core.

Maybe it belongs in a plugin.

And if the plugin API isn't powerful enough?

I'll make it better.
